# Security Policy

## Reporting a vulnerability

Please report security issues through GitHub's private vulnerability reporting for this repository. Do not open a public issue for an unpatched vulnerability. If private reporting is unavailable, contact the maintainers privately through GitHub.

Include the affected version or commit, steps to reproduce, and the impact. Please avoid sharing live credentials or customer data in a report.

## Supported versions

Security fixes are applied to the current `master` branch. Upgrade to the latest available release or commit before reporting an issue when possible.
